# «Я СКАЗАЛА — СТАРТУЕМ!» (2013)

Ностальгическая веб-игра для олдфагов по мотивам легендарного питерского мема 2013 года:

1. **Фаза 1 — Питерский автобус № 24 (камера 3GP 2013 года):** шагай по салону к кабине водителя, отбивай реплики пассажиров и кондуктора каноничными фразами, доводи напор до 100% и жми **«Я СКАЗАЛА — СТАРТУЕМ!»**, чтобы выкинуть водителя из-за руля.
2. **Фаза 2 — Мини-GTA 2 (Питер → Джип в Москве):** гоняй и дрифти на автобусе по 2.5D-Петербургу с каналом Грибоедова, собирай рубли на остановках, сноси кордоны ударной волной, пересаживайся на **Джип в Москве** и лови психоделический **«🌀 КУЛЬТУРНЫЙ ПРИХОД»** с галлюцинациями и очками `×3`.
3. **Своя озвучка MP3:** встроенный русский голос (`speechSynthesis`) + возможность закинуть реальные MP3-нарезки прямо в интерфейсе или в `audio/voice/`.

## Локальный запуск

Любой статический сервер (или просто открыть `index.html`):

```bash
python3 -m http.server 8765
```

## Деплой на GitHub Pages

Проект полностью статический (без сборщика, с `.nojekyll` и относительными путями `./`). Достаточно запушить на GitHub и включить Pages из корня ветки `main`.
